# Nabeela Rafi — Portfolio

Plain HTML, CSS and JavaScript. No build step, so it runs straight on GitHub Pages.

## Files
- `index.html` — all content (edit text, projects and links here)
- `style.css` — design and colours (change `--accent` at the top to re-theme)
- `script.js` — mobile menu, project filters, contact form, scroll effects
- `assets/` — put `Nabeela-Rafi-CV.pdf` and (optionally) your photo here

## Before you publish
1. Replace `https://www.linkedin.com/in/YOUR-LINKEDIN` in `index.html` with your LinkedIn URL.
2. Add your CV as `assets/Nabeela-Rafi-CV.pdf`.
3. Optional photo: save it as `assets/profile.jpg`, then in `index.html` replace
   `<div class="avatar">NR</div>` with
   `<div class="avatar"><img src="assets/profile.jpg" alt="Nabeela Rafi" /></div>`.

## Deploy to GitHub Pages
1. Open your repo `nabeela-rafi/nabeela-rafi` on GitHub.
2. Delete the old files (or make a new repo) and upload `index.html`, `style.css`, `script.js` and the `assets` folder to the root.
3. Settings → Pages → Source: **Deploy from a branch**, Branch: `main` / `(root)` → Save.
4. Your site is live at `https://nabeela-rafi.github.io/nabeela-rafi/` within a minute or two.
